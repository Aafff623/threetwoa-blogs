# Glossary · 前端 / 博客 UI

人 ⇄ Agent 对齐用。领域硬定义以 `CONTEXT.md` 为准；此处补界面层俗称映射。

| 界面说法 | 规范词 | 说明 |
|----------|--------|------|
| 博客文章 / 博文 | **Post** | `pages/posts/` |
| 分类页环图 | Category 图表 | ECharts · `Sakura*Chart` |
| 标签柱图 | Tag 图表 | 同上 |
| 归档时间线 | **Archive** | `/archives/` |
| 灯箱 / 图片预览 | ImageGalleryViewer | `App.vue` 挂载 |
| 公告栏 | SakuraNoticeBoard | 首页动态 |
| 网址导航 / 抽卡 | Navigation* | 加权随机跳转 |
| 友链卡 | links 页组件 | Stage 5 |
| 信封留言 | 留言板动画 | Stage 6 |
| 相册门禁 | gallery 加密 UI | frontmatter password ≠ 真保密 |
| 搜索页 | Fuse 搜索 UI | `/search` + Search index |
| 加载遮罩 | FOUC Guard | `plugins/va-fouc-loader` |
| 主题皮肤 | **Theme** | 勿称 skin |
| 小部件 | **Component** | 勿称 widget |
