# Valaxy Blog Context

This context covers the Valaxy static blog, including its local search capability and content publishing workflow. It defines the domain language used when discussing the site, its content, and its features.

## Language

**Post**:
A single blog article, authored as a Markdown file under `pages/posts/`.
_Avoid_: article, blog entry, blog post

**Page**:
Any route generated from a file under `pages/`, including posts, the index, archives, categories, tags, links, and about pages.
_Avoid_: route, view

**Route**:
The URL path generated by Valaxy from a file in `pages/`. Defined in `.valaxy/route-map.d.ts`.
_Avoid_: URL, path

**Layout**:
A Vue component that wraps a page's visual structure, provided by the theme or overridden in `layouts/`.
_Avoid_: template, wrapper

**Theme**:
The packaged UI set (`valaxy-theme-sakura`) that provides layouts, components, and styles.
_Avoid_: skin, visual style

**Component**:
A Vue component, either custom in `components/` or supplied by Valaxy / the theme, auto-registered on demand.
_Avoid_: widget, element

**Front matter**:
The YAML metadata block at the top of a Markdown page.
_Avoid_: meta header, page metadata

**Site config**:
Site-level metadata in `site.config.ts` (url, lang, title, author, social links, search, sponsor).
_Avoid_: site settings, blog config

**Valaxy config**:
Framework and theme configuration in `valaxy.config.ts` (theme, UnoCSS safelist, addons).
_Avoid_: framework settings

**Search index**:
The pre-built, JSON-based searchable data generated at build time for local search.
_Avoid_: search database, search cache

**Search provider**:
The mechanism that answers a user's query. For this repo it is Valaxy's built-in local search.
_Avoid_: search backend, search engine

**Safelist**:
The explicit list of UnoCSS icon class names in `valaxy.config.ts` that must be preserved at build time.
_Avoid_: whitelist

**SSG**:
Static Site Generation. The build process that produces the `dist/` output from source files.
_Avoid_: static build (ambiguous with "build script")

**Category**:
A classification for a Post. A Post may belong to one Category.
_Avoid_: folder, group

**Tag**:
A keyword attached to a Post. A Post may have many Tags.
_Avoid_: label, keyword

**Archive**:
The chronological list of all Posts, typically at `/archives/`.
_Avoid_: history, timeline

**Excerpt**:
A short summary of a Post, either defined in front matter or auto-generated from the body.
_Avoid_: summary, preview

**Social link**:
An external link to the author's social profile, shown in the site footer or sidebar.
_Avoid_: social media, profile link

**Sponsor**:
The donation / support section configured in site config, usually showing QR codes.
_Avoid_: donate, tip

**Locale**:
A language-specific translation file under `locales/` used to override theme strings.
_Avoid_: translation file, lang file

## Relationships

- A **Post** is a kind of **Page**.
- A **Page** uses exactly one **Layout**.
- The **Theme** supplies the default **Layout** and **Component** set.
- **Front matter** belongs to a **Page**.
- The **Search index** is generated from all **Pages** and consumed by the **Search provider**.
- A **Post** may have one **Category** and many **Tags**.
- The **Archive** aggregates all **Posts** by date.

## Invariants

- Content is authored only as Markdown or Vue files under `pages/`.
- Site metadata lives in `site.config.ts`; framework/theme config lives in `valaxy.config.ts`.
- Custom styles are injected through `styles/index.scss` and `styles/css-vars.scss`.
- Custom components in `components/` are auto-registered by `unplugin-vue-components`.
- The site is built with SSG by default; the output is `dist/`.

## Flagged ambiguities

- "blog config" was previously used to mean both `site.config.ts` and `valaxy.config.ts`. Resolved: use **Site config** and **Valaxy config** respectively.
- "search engine" was previously used to mean either the UI or the provider. Resolved: **Search provider** answers queries; the UI is just the search UI.

## Open questions

- The site title, author, description, and social links have been personalized; review periodically as the site evolves.
- Search is enabled via Fuse and the `/search` page is active; future work may include search highlight and recent queries.
- The content publishing workflow (Obsidian → R2 → blog post) is established; future work may include scheduled publishing and content series.
